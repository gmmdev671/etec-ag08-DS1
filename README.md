# Pesquisa de Opinião — TudoWeb

Projeto desenvolvido em Python para coletar a opinião dos clientes sobre o
atendimento prestado pela empresa TudoWeb.

## Opções da pesquisa

- 1 — EXCELENTE
- 2 — BOM
- 3 — RUIM

## Funcionamento

O programa solicita o nome, a idade e a opinião de cada entrevistado. Ao final,
exibe:

- A quantidade de respostas "EXCELENTE";
- A quantidade de respostas "RUIM".

A estrutura de repetição `for` é utilizada para entrevistar os participantes.
As estruturas de decisão `if`, `elif` e `else` são usadas para verificar e
contabilizar as opiniões.

## Testes

O programa foi testado inicialmente com 10 entrevistados. Para a execução
final, a quantidade foi configurada para 50 entrevistados.

## Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

`python pesquisa_opiniao.py`

## Evidências

Os prints do código e da execução estão disponíveis na pasta `prints`.
